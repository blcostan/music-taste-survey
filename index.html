GitHub Pages + Free Backend Guide

Collect real responses from visitors worldwide

Why do you need a backend? GitHub Pages hosts static HTML/JS files. Without a backend endpoint, localStorage only saves data on each individual visitor's own browser. Connect one of the free services below to aggregate everyone's responses!

1 Host this file on GitHub Pages (2 minutes)

  1. Create a new public repository on GitHub (e.g., music-taste-survey).
  2. Upload this file and name it index.html.
  3. Go to Settings → Pages, set Source to Deploy from a branch (main / /root), and click Save.

2 Choose a Free Backend Service

Option A: Formspree

Create a free form at formspree.io, copy your endpoint URL (https://formspree.io/f/xyz), and paste it below.

Option B: Google Sheets

Open a Google Sheet → Extensions → Apps Script, deploy a doPost(e) web app, and paste the Web App URL below.

Option C: Supabase

Create a free Postgres table in supabase.com and use its REST API URL (/rest/v1/responses) with your anon key.

When set, every survey submission will automatically send a JSON POST request to your URL in addition to updating the dashboard.
